AVIATOR ANALYSIS PRO - ANDROID PROJECT

This is a starter Android app with:
1. An illustrative multiplier probability calculator.
2. A manual historical-round statistics analyzer.
3. A SHA-256 text hashing tool.

It does NOT predict future Aviator crash points and does not claim to verify a live 1xBet/Spribe round. The 0.97/M probability display is an illustrative 97% RTP model, not confirmation of the exact operator implementation.

HOW TO BUILD AN APK (GitHub Actions):
1. Extract this ZIP.
2. Create a new empty repository on GitHub.
3. Upload the CONTENTS of this folder (not the ZIP itself) to the repository's main branch.
4. Open the repository's Actions tab.
5. Select "Build Android APK" and press "Run workflow" if it has not started automatically.
6. When the workflow finishes, open the run and download the artifact named "AviatorAnalysisPro-debug-apk".
7. Extract the downloaded artifact ZIP. It contains app-debug.apk.
8. Transfer app-debug.apk to your Android phone and install it. You may need to allow installation from that file manager.

For editing/building locally, open this folder in Android Studio and build the app.
